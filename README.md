# 🏰 Hogwarts Academy - Sistema de Gestão Mágica

> **Status do Projeto:** 🟡 Em Desenvolvimento (Fase 1 - Java Core & POO)

O **Hogwarts Academy** é uma aplicação backend projetada como um **Projeto Evolutivo de Portfólio**. Seu principal objetivo é conectar a teoria de estudos diários à prática de engenharia de software de nível de mercado, evoluindo a arquitetura do sistema em camadas à medida que novos conceitos e tecnologias são dominados.

O domínio do sistema simula a gestão acadêmica da Escola de Magia e Bruxaria de Hogwarts, cobrindo o controle de alunos, casas, matrículas, disciplinas, gestão de feitiços e inventários.

---

## 🚀 Propósito e Arquitetura Evolutiva

Em vez de construir múltiplos projetos pequenos e desconectados, esta aplicação cresce de forma contínua. O projeto foi planejado para percorrer três grandes fases evolutivas:

```text
[ Fase 1: Java Core & POO ] ──► [ Fase 2: Persistência & Docker ] ──► [ Fase 3: Ecossistema Spring Boot ]
 Lógica de domínio, Enums,       Gerenciador de Build (Maven),        Arquitetura em Camadas, APIs REST,
 Collections, Streams e          Banco Relacional (PostgreSQL)        Spring Data JPA, DTOs e Mappers,
 Exceções Customizadas.           containers com Docker.               validações e segurança.
```
## 🎯 Roadmap de Aprendizado & Funcionalidades

## 🔴 Fase 1: Fundação em Java Core & POO (Fase Atual)
[x] Modelagem Orientada a Objetos (Classes, Atributos, Métodos, Encapsulamento).

[x] Aplicação de Herança, Polimorfismo e Classes Abstratas.

[ ] Tratamento defensivo de erros e Exceções Customizadas (ex: FeiticoInvalidoException, CasaLotadaException).

[ ] Manipulação de dados na memória com o Collections Framework (List, Set, Map).

[ ] Processamento de dados e filtros utilizando Lambdas & Stream API.

## 🟡 Fase 2: Gerenciamento de Build & Banco de Dados Relacional (Em Breve)
[ ] Migração e estruturação de dependências utilizando Apache Maven (arquivo pom.xml).

[ ] Subida e orquestração de ambiente de banco de dados via Docker & Docker Compose[cite: 2, 3].

[ ] Modelagem de banco de dados relacional e scripts SQL no PostgreSQL (CREATE TABLE, INSERT, JOIN).

[ ] Integração do Java com banco de dados para persistência real de dados.

## 🟢 Fase 3: Framework Spring Boot & APIs RESTful (Futuro)
[ ] Construção de uma API RESTful expondo endpoints HTTP (GET, POST, PUT, DELETE).

[ ] Aplicação de Arquitetura em Camadas (Controller, Service, Repository).

[ ] Mapeamento Objeto-Relacional (ORM) com Spring Data JPA & Hibernate[cite: 2].

[ ] Padrões de projeto de mercado: uso de DTOs (Data Transfer Objects), Mappers e Validations.

[ ] Implementação de Testes Automatizados e documentação da API com OpenAPI/Swagger.
